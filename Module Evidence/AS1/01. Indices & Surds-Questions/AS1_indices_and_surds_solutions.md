## 1. Mark Scheme Notation Guide

The supplied mark scheme uses short mark codes beside each official working line.  Commonly:

- `M` usually means method mark.
- `A` usually means accuracy mark, although this mark scheme mainly uses `W` rather than `A`.
- `B` usually means an independent mark.
- `W` or `MW` may represent written, working, or method-with-working marks depending on the source.
- A code such as `M1W1` is recorded as two marks.
- A code such as `MW2` is recorded as two marks attached to the official working line.

The exact meaning of each mark code should be interpreted according to the awarding body’s mark scheme conventions.
