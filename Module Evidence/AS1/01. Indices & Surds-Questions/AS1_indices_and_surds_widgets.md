# Interactive Widgets for CCEA AS1 Pure Mathematics Indices and Surds

**Pack ID:** AS1IndicesAndSurds

No interactive widgets were required for this question pack.  The questions are better practised through written exam-style working, especially because they focus on exact algebraic manipulation, rationalising denominators, and solving equations using index laws.

A widget could be used for optional checking, but it would risk replacing the written method that the mark scheme rewards.  Therefore no widget placeholder has been inserted into the questions or solutions files.
